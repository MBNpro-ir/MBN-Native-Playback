# MBN native playback libraries

Public third-party library recipes only. Application source is private. Based on w3bward/libmpv-lgpl, retaining the LGPL and attribution. Changes enable Windows Schannel HTTPS networking and D3D11 hardware output. Releases include corresponding sources, notices, configuration and hashes.

Build on Ubuntu 24.04 with ./build.sh; verify with python3 verify.py dist. CI checks license configuration and seeking/frame stepping before publishing.
